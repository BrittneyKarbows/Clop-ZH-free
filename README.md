# Clop-ZH-Free

基于 FuzzyIdeas/Clop 公开源代码修改的 macOS 文件优化工具，适配 Apple Silicon，提供主要界面的简体中文本地化和免费不限次数的本地优化功能。

## 项目说明

本项目用于个人学习、研究与技术交流，研究内容包括 macOS 应用开发、文件优化流程和中文界面适配。

Clop 原版由 **The low-tech guys** 开发和维护。本项目为独立修改分支，与原作者没有官方合作或背书关系。原始代码、图标及相关素材的版权归各自权利人所有。

**如果 Clop 对你有帮助，请通过官方网站下载原版，并购买 Clop Pro 支持原作者持续开发。支持正版，尊重开发者的劳动成果。**

- [Clop 官方网站](https://lowtechguys.com/clop/)
- [Clop 原始源码](https://github.com/FuzzyIdeas/Clop)
- [原作者 The low-tech guys](https://lowtechguys.com/)

## 主要功能

- 图片压缩、格式转换、缩放和裁剪
- 视频压缩、分辨率调整和播放速度修改
- 音频压缩、码率调整和格式转换
- PDF 优化和页面裁剪
- 剪贴板自动优化、文件夹监控和拖放处理
- 批量优化、原件备份和恢复
- macOS 快捷指令、命令行和 MCP 集成

## 本分支的修改

- 将主要菜单、设置、引导、结果窗口和批处理界面翻译为简体中文
- 取消 Pro 授权、试用期和每会话处理次数限制
- 开放批量处理和 MCP 功能
- 移除 Paddle 授权组件、Sparkle 更新组件及许可证页面
- 使用独立的应用标识、缓存目录、`clop-zh` 命令和 `clop-zh://` URL 方案
- 修复公开源码中的部分构建问题，提供 Apple Silicon 构建脚本

MCP 的代理写入和脚本执行仍需用户主动授权。

## 安装

1. 从本仓库的 Releases 下载 `Clop-3.5.1-zh-CN-Free-arm64.dmg`。
2. 打开安装包，将 **Clop 中文** 拖入 **Applications**。
3. 从「应用程序」打开，在菜单栏进入设置，配置所需功能。

当前版本为 Apple Silicon 原生 arm64 构建，部署目标为 macOS 13.0，已在 macOS 15.8.2 上测试。安装包使用本地临时签名，尚未经过 Apple 公证。

## 从源码构建

构建环境使用 Xcode 26.3。进入项目根目录后运行：

```bash
./Scripts/build-zh-arm64.sh
```

脚本会解析 Swift 依赖、下载并校验上游优化工具资源，然后生成应用。

构建产物位于：

```text
build/zh-arm64/Build/Products/Release/Clop.app
```

## 验证情况

- Apple Silicon arm64 Release 构建成功
- 应用签名和磁盘映像完整性检查通过
- 同一应用会话中成功处理 8 个逐文件样例和 12 个批处理样例
- MCP 在写入授权关闭时会拒绝代理修改设置

## 已知限制

- 部分第三方界面、命令行和动态提示仍显示英文
- 当前分支未包含依赖 WarpDrop 组件的安全分享链接
- 自动剪贴板监听、全部界面布局和快捷指令尚未逐项验证
- VideoToolbox 硬件编码曾在本机测试中创建会话失败
